# Contributing

Thank you for improving MaxRead.

1. Open an issue for substantial behavior or security changes.
2. Create a focused branch and add tests for changed behavior.
3. Run `python -m pytest`, `python -m compileall -q .`, `ruff check .`, and `npm test` when applicable.
4. Do not include production credentials, Feishu links or identifiers, user content, generated paper data, logs, or internal infrastructure details.
5. By submitting a contribution, you agree that it is licensed under AGPL-3.0-only.

Security reports should follow [SECURITY.md](SECURITY.md), not a public issue.
